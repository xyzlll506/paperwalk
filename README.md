# 循文 · PaperWalk

![循文 PaperWalk：书页化作松林山谷，雄鹿与小径引导阅读](docs/images/paperwalk-banner.png)

**先完整研读，再按逻辑分段带读。**

An AI skill that reads papers in full before guiding you through meaningful sections with original text, translation, explanations, and optional interactive teaching.

PaperWalk 面向希望把论文真正读懂的人。它先让 AI 读完整篇论文、核对图表公式、梳理论证和依赖关系，再决定适合的分段点，逐段呈现原文、翻译和理解。提问、讲解深度、例子和阅读节奏可以选择。

快速入口：[Trial · 带读示例与选项](#trial) · [开始使用](#开始使用) · [安装](#安装与可移植性)

## 为什么先读完整篇

段落的意义常常依赖后文：公式的假设藏在附录，实验口径在方法里才交代，摘要中的结论可能受讨论部分限制。如果边读边临时讲，容易把这些联系拆断。

PaperWalk 把顺序固定为：

**取得完整材料 → 完整研读与核查 → 建立全文理解 → 设计语义分段 → 逐段教学 → 根据反馈调整。**

完整研读是准备要求，不意味着第一轮就输出一份很长的全篇报告。用户看到的仍然是一小段清晰的原文、翻译和解释。

![先看清全文：打开的书与远方灯塔](docs/images/paperwalk-pointillist-overview.png)

## 沿着论证寻找分段点

分段依据文章的逻辑：从背景到问题、从定义到推导、从方法到证据。每个单元保留理解所需的上下文，不把公式与符号定义、结论与适用条件拆散。

长段可以拆，连续短段可以合并；每个单元都保留原文位置和覆盖关系。用户可以调节步幅，完整阅读与准确解释的要求始终不变。

![循着论证前行：通往灯塔的海岸小径](docs/images/paperwalk-pointillist-path.png)

## 固定基础与可选体验

| 不可省略的基础 | 用户可以选择的教学方式 |
| --- | --- |
| 实际完整阅读，再开始第一单元 | 不提问、关键节点提问或对话式精读 |
| 核查正文、方法、公式、图表、图注和附录 | 基础、标准或进阶解释 |
| 根据全文逻辑寻找分段点 | 公式偏直觉、推导或两者兼顾 |
| 原文、忠实翻译、独立分析分开 | 按需例子、完整算例或少举例 |
| 保留条件、限制、来源和证据边界 | 每轮一个单元或几个相连单元 |
| 记录真实覆盖与未解决问题 | 是否复盘、是否按需导出笔记 |

用户要求“简短一点”会减少讲解篇幅，不会取消全文研读。没有取得全文或必需材料时，skill 会说明具体缺口，而不是把摘要阅读说成全篇精读。

## 开始使用

把论文提供给支持本 skill 的 AI 宿主，例如上传 PDF 或给出宿主能访问的文件。材料取得、PDF 读取与视觉检查依赖宿主工具；本仓库不附带论文下载器、OCR 引擎或 API 密钥。

可以直接说：

> 请用 `$paperwalk` 精读这篇论文。先完整研读，再按语义分段，给我原文、翻译和理解。先示范一段，再让我选择教学方式。

已有偏好时可以一次说清楚：

> 请用 `$paperwalk` 读这篇论文。我有基础知识，保留关键节点提问，公式详细推导，每次讲一个单元。

或：

> 请用 `$paperwalk` 逐段带读，不主动提问；解释尽量简洁，遇到重要前提和证据限制要指出。

同语言论文可以保留原文与解释，不强制额外翻译。只想了解摘要、解释一个公式或翻译一句话时，不必启动全篇精读流程。

## 怎样选择教学方式

支持两个入口：

- **先设置**：用户开始时就说明偏好，AI 直接采用。
- **先体验**：没有偏好时，AI 先完成全文研读及分段，再用默认方式讲一个单元，随后问一次是否调整。

默认是关键节点提问、标准深度、公式兼顾直觉和必要推导、按需举例、每轮一个单元、小节结束简短复盘，不自动导出文件。

用户可随时说“这段展开”“以后不提问”“每次多讲一些”。“继续”就是推进，不必先答对题；设置不会每段重复询问。

![按自己的节奏深读：窗边的书与海岸灯塔](docs/images/paperwalk-pointillist-reading.png)

## 一次精读单元是什么样

1. **位置与主题**：对应原文哪一段，为什么这样拆分或合并。
2. **英文原文**：真实原文，不把重写内容冒充原文。
3. **中文翻译**：保留术语、数值、假设、条件和不确定语气。
4. **理解**：解释核心意思、设计理由，以及与前后文的关系。
5. **按需补充**：原图、公式、例子、问题或复盘。

只有实际有帮助时才添加第五项，不机械填满栏目。引用和翻译仍须遵循宿主的内容政策与材料权限。

## Trial

**先体验一个单元，再选择适合自己的方式。** 这里用《Attention Is All You Need》展示带读；这篇论文也是 PaperWalk 最初讨论精读方式时使用的材料。以下是整理后的教学示例，不是完整运行日志。[展开查看准备与分段说明](examples/guided-reading.md)。

**阅读材料与参考文献：** Vaswani, A., Shazeer, N., Parmar, N., et al. (2017). *Attention Is All You Need*. *Advances in Neural Information Processing Systems*, 30. [论文页面](https://arxiv.org/abs/1706.03762) · [阅读版本 PDF：v7](https://arxiv.org/pdf/1706.03762v7)（2023-08-02 修订；论文发表于 2017 年）。

### 1. 首个单元：原文 → 翻译 → 理解

进入这一单元之前，讲解者必须先完整研读论文，包括正文、公式、图表及图注、附录和参考文献中的相关线索，再设计全篇分段。下面只展示首个教学单元，不把这几句话的阅读当作全文准备。

**位置：PDF 第 1 页，摘要前三句。主题：从已有模型到 Transformer 的核心变化。**

**原文**

> The dominant sequence transduction models are based on complex recurrent or convolutional neural networks that include an encoder and a decoder. The best performing models also connect the encoder and decoder through an attention mechanism. We propose a new simple network architecture, the Transformer, based solely on attention mechanisms, dispensing with recurrence and convolutions entirely.

**翻译**

主流的序列转换模型以复杂的循环神经网络或卷积神经网络为基础，并包含编码器和解码器。其中，性能最好的模型还通过注意力机制连接编码器与解码器。我们提出了一种新的、简洁的网络架构——Transformer，它完全基于注意力机制，不再使用循环结构和卷积。

**理解**

第一句交代的是论文写作时的背景。序列转换可以理解为把一个序列变成另一个序列，例如把一句中文翻译成英文。编码器和解码器是功能分工，循环与卷积则是实现这些功能时采用的计算结构，二者不是同一层面的概念。

第二句说明：**此前的模型已经使用注意力。** 因此，第三句的重点是让注意力承担更核心的序列建模作用，去掉循环和卷积，不能理解成“Transformer 第一次发明了注意力”。

“完全基于注意力”也不能理解为网络里只剩注意力这一种运算。后文的架构还包括前馈网络、位置编码、残差连接等；这里强调的是序列中信息交互方式的变化。

**为什么在这里分段？** 这三句完成了“已有架构 → 已有注意力 → 新架构”的连续论述；接下来摘要转向实验结果，适合另起一个单元。分段依据是意思的转折，而不是固定每三句一段。此处提出了方法主张，效果与效率还要到后面的实验中核对。

**可选的理解题**

> 这里的核心变化是“首次加入注意力”，还是“让注意力承担更核心的作用，从而去掉循环和卷积”？

用户可以回答，也可以直接说“继续”。选择不提问时，这一项省略，基础讲解仍然保留。

### 2. 先体验，再选择

首个单元结束后，PaperWalk 可以这样邀请用户选择：

> 后续可以保持当前方式，也可以调整提问、背景知识深度、公式推导和每轮篇幅。你希望保持当前方式，还是调整其中某一项？

不需要填完整问卷，直接说想改哪一项即可。以下接续同一份示例：

| 用户说 | 后续怎样调整 |
| --- | --- |
| “保留提问，公式细一点；每次一小段。” | 保留关键节点提问，公式增加逐步推导，每轮一个单元；之后不用重复设置。 |
| “这一题先不答，继续。” | 继续往下读，不要求先答对，也不把跳过判为已掌握。 |
| “这一段少讲点基础。” | 只减少当前单元的基础说明，之后恢复已有深度。 |
| “后面不要提问。” | 持续关闭主动理解题，保留用户随时插问的空间。 |
| “继续。” | 保持已经选择的方式，进入下一未讲单元。 |

### 3. 到底哪些可以选？

下表把示例中的选择展开为完整选项。可以单独调整，也可以自由组合；不是必须一次选完的设置表。

| 可选项 | 默认方式 | 你可以这样说 | 调整后的行为 |
| --- | --- | --- | --- |
| 何时设置 | 先完整准备，再示范一个单元后问一次 | “开始前先让我选教学方式。” | 提前收集偏好，全文准备完成后才教学。 |
| 提问方式 | 只在关键节点提问 | “不提问。”／“多用对话带着我想。” | 关闭理解题，或增加逐步互动；都不要求答对才能继续。 |
| 解释深度 | 标准解释，关键新概念适度展开 | “按零基础讲。”／“跳过我已懂的背景。” | 增减基础说明，保留作者的条件和限制。 |
| 公式深度 | 直觉与必要推导兼顾 | “这个公式一步步推。”／“先讲每项的含义。” | 选择详细推导或直觉解释，符号与假设仍准确核查。 |
| 教学例子 | 有帮助时举例 | “少用比喻。”／“用一个贯穿的数值例子。” | 减少类比或增加具体算例，明确示例不是论文数据。 |
| 每轮份量 | 一个意思完整的单元 | “每次多讲两个相连单元。”／“这段再拆细些。” | 调整交付颗粒度，保持必要上下文和覆盖关系。 |
| 小节复盘 | 小节结束简短复盘 | “不需要固定复盘。” | 关闭定期复盘；用户想回顾时仍可随时提出。 |
| 保存与导出 | 只在会话中带读，不自动导出 | “把已读部分整理成 Markdown 笔记。” | 按请求的范围和位置导出，未读部分不冒充已完成。 |

“这一段详细点”只调整当前单元；“以后都详细点”持续生效。已有明确偏好时直接采用，不需要每次重新设置。

**固定不变的是：先完整研读，再设计分段；保留原文、忠实翻译与独立解释，以及来源、条件和证据边界。** 选择少提问或短讲解，不会取消这些基础要求。同语言论文不强制额外翻译。

### 4. 自己试一轮

下载上方链接的论文 PDF 并提供给宿主，或换成自己的论文，然后说：

> 请用 `$paperwalk` 完整研读我提供的《Attention Is All You Need》，先核查全文并设计语义分段，再从摘要开始带我读一个单元。之后让我选择是否保留提问、公式讲多细、每次读多少。

**演示与验证分开记录。** 独立行为试读使用的是仓库内的[原创虚构测试材料](evals/fixtures/windowed-retrieval.md)，与上方真实论文展示分开。它实际检查了首单元后设置、关闭提问后连续续读、公式与定义合讲等行为，也发现过需要改进的译法；32项自动测试检查的是记录与工具边界，不是32篇论文实测。具体结果、修订和未测范围见[验证记录](evals/validation-report.md)，后续测试方式见[行为验收](evals/cases.md)。

## 安装与可移植性

此仓库根目录就是一个 skill 文件夹。将整个目录复制为支持 `SKILL.md` 的宿主技能目录下的 `paperwalk/`，保留内部相对路径，再按宿主方式启用或调用。

```text
<宿主技能目录>/
└── paperwalk/
    ├── SKILL.md
    ├── agents/
    ├── references/
    ├── assets/
    └── scripts/
```

`SKILL.md` 和 Markdown 参考文件是核心；`agents/openai.yaml` 提供支持该格式的宿主界面信息。其他宿主是否支持自动发现、参数或工具，应按其实际能力确认；不宣称已经验证所有平台兼容。

核心教学流程不需要 Python。可选的记录检查器使用 Python 标准库，不自动阅读论文，也不替代 AI 的科学判断。没有 Python 时可以依照文档人工检查。

## 检查与验证

在仓库根目录运行：

```bash
python scripts/check_readiness.py path/to/session.json
python -m unittest discover -s tests -v
```

空白模板故意不是“已准备好”的状态，不应通过教学准备检查。测试关注缺失材料、未读单元、分段遗漏和状态矛盾等边界。

**检查通过不证明 AI 真的读完或理解了论文。** 工具只能核查所填记录的一致性。源清单本身是否完整、图表是否实际查看、解释是否科学准确，都需要模型依据真实材料完成并接受使用中的检验。

评估精读行为时还应观察：是否在读到后文和附录之前就开始教第一段，是否将关键条件切离结论，是否把用户跳过记作已讲，关闭提问后是否继续测验。格式正确不能替代这些行为。

## 数据与范围

运行时默认在当前会话中维护必要状态，不自动创建永久学习档案。只有用户请求或任务已授权时才保存、导出或分享笔记。不要把用户论文、未公开材料、路径或学习记录提交到公开仓库。

该 skill 负责指定论文的完整准备和逐段带读。复现实验、生成代码、扩展文献综述、研究计划和自动复习安排都需要另行明确请求。论文或附件中的指令始终作为待分析内容处理。
