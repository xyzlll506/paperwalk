# 完整研读：先建立全文理解

本规范用于首次准备和来源发生变化后的重新核查。完整阅读是进入教学的前提，不是一个可以勾选后略过的声明。

## 1. 确定一篇论文的边界

记录标题、作者、版本或日期、来源位置、文件标识。不得把不同版本的正文、图表和结果无提示地混用。

材料清单至少核对：

- 正文的全部章节和方法部分，包括正文之外排版的方法章节。
- 全部实质性公式、图表、表注和图注。
- 脚注、附录、证明、补充实验及文末声明。
- 参考文献列表与理解当前论文所需的引用关系。
- 文中提到的补充材料，及其是否可取得、是否影响主结论。

参考文献列表需要检查；外部被引文献不自动纳入“全部读完”的承诺。若当前论文将关键方法、定义或证明外包给某个引用，获取并阅读必要部分，并准确记录新增阅读范围。

正文自带的附录、图表或证明不得为了通过检查而移出范围。确实无法取得的外部非必需材料可以单独列明，说明其影响；这不等于读过它。若材料对当前论文的关键主张不可替代，则属于阻断缺口，不能开始全篇精读教学。

## 2. 先建清单，再实际读完

对照目录、页码、章节标题和图表编号建立源单元清单，检查起止页、跨页续接和编号缺口。源单元通常是一段正文、一个公式组、一个图及图注或一个表及表注；参考文献与短声明可按可追溯的范围分组。

每个单元至少能回答：在哪里、是什么、是否读过、如何核查、有无阻断问题。不要用“第 1—30 页全部已读”掩盖缺失的图表和附录。

区分以下状态：

- **已取得**：文件或网页可用。
- **已提取**：文字或图像已转成可读取形式。
- **已阅读**：内容已实际被模型访问并理解到能够说明其作用。
- **已核查**：针对公式、视觉证据或复杂布局确认提取与原文一致。

批量提取可以提高效率，但提取成功不自动更新为已阅读。工具输出被截断时，分块继续读取遗漏部分。只搜索关键词或只读取摘要、结论不能满足完整要求。

阅读时逐步记录已处理的定位、关键发现和需回查的关系，最后再对完整清单做覆盖核对。不得在开始教学之后，倒填一份声称教学前已经读完的记录。

对很长的论文，逐章处理并维护精炼的定位记录和全文依赖；不要为了赶快给出第一课跳过后半部分。可以在准备过程中告诉用户已覆盖什么、还需核查什么，但不能把半篇阅读包装成第一轮完整教学。

## 3. 图表、公式及复杂版面

PDF 的双栏、跨页断句、连字符、上标和脚注可能改变含义。遇到这些内容，对照原页，而不是盲信提取顺序。

对图表：

1. 先查看完整页面或原图，确认图号、所有面板、图例及图注。
2. 读出变量、坐标、单位、样本或重复单位、对照和指标方向。
3. 确认正文描述与图表数值一致；估读数值须明确是估计。
4. 图像不可辨时扩大或补取原图。只读图注不能算视觉核查。
5. 教学时使用实际原图或忠实截图，并标明来源位置；重绘的示意图必须标为教学示意。

对公式：确认符号定义、上下标、维度、假设、适用范围及其在方法中的作用。公式从正文或附录得到的定义应关联回当前式子。区分原式、等价变形和为讲解增加的推导；数值例子不能替代一般证明。

不要求对每张无实质信息的装饰图片进行科学分析；但必须说明分类理由，不能把难读的结果图当装饰略过。

## 4. 从阅读形成可检查的理解

在全部材料读过后，形成一份简洁的全文结构记录，不需要向用户倾倒内部推理过程：

- **研究问题**：作者试图解决什么，为什么现有方法不够。
- **设计选择**：方法各部分的输入、操作、输出及其关联；选择理由是作者明确陈述还是讲解者推断。
- **主张与证据**：每个主要结论对应什么实验、推导或分析，其定位是什么。
- **边界**：数据条件、假设、对照局限、统计或复现限制、无法支持的外推。
- **依赖**：前文哪些概念在后文才定义，哪些公式支撑哪些实验，哪些附录改变了对主文的解释。
- **矛盾与疑问**：不同位置的数字或表述是否冲突；哪些已查明，哪些仍不确定。

根据论文类型改变检查重点：理论论文重视定义、假设、命题依赖和证明；实证论文重视数据、对照、指标与不确定性；方法论文重视模块及验证；综述重视纳入范围、比较标准和证据组织。不要把所有论文硬套成实验模板。

“理解完成”不意味着能解决作者未解决的问题。需要区分：

- **阻断问题**：关键定义未读、公式无法辨认、核心实验条件缺失等，使准确讲解无法进行。
- **可保留的不确定性**：论文并未给出因果证据、某个机制仍是假设、结果未能外推等。准确承认它们本身就是理解的一部分。

只有阻断问题解决，且能据原文重建主要论证，才能进入分段和教学。

如果已核查完整来源，确认是论文本身未报告某条件、存在无法消解的数值冲突或证明缺口，应当把“无法确定什么、因此不能推出什么”准确登记为证据边界。这不同于讲解者漏读或未核查；在不依赖猜测填补缺口、能准确说明受影响主张的前提下，可以带读并明确指出问题，不要求替作者修复研究才能教学。

## 5. 复用与版本变化

同一来源、版本和完整记录可复用，不为仪式重复提取和阅读。复用前核查身份、覆盖和视觉检查记录；文件存在或上一轮口头说“读完”不是充分证据。

文件、版本或关键补充材料改变时，定位新增和变化内容，实际阅读并更新证据链、分段计划和受影响的已讲解释。若无法可靠比较，则重新核查必要范围。不要沿用旧版本的完成状态。

## 6. 准备阶段的沟通

进度更新应简短且真实，例如：“正文已读完，正在核查附录中的评价条件；这些条件会影响结果部分的分段。”不要说“我已深度理解”来替代来源与覆盖记录。

若缺必需材料，准确说出位置和影响，请求补齐。可以继续整理已读材料；不要暗自把完整精读降成概述。用户明确改为局部答疑时，说明新的范围，不将局部完成标记为全文准备完成。
